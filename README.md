# Ami's Day

A native Windows anniversary game. Follow Ami through a day out, choose where she goes, and see her choices at the end.

## Build

Install the MSYS2 UCRT64 C++ toolchain and run `New Text Document.bat`. It expects MSYS2 at `C:\msys64` and builds `AmisDay.exe` with the soundtrack embedded. You can run the executable on its own.

## Controls

- Arrow keys to move
- Z to interact or confirm
- X to cancel
- M to toggle music
- F11 to toggle fullscreen
